# Week 13 — Review response

## Self-identified usability issue (November 26)
The project owner observed that the initial page was overwhelming because all controls and views were open. In response, the initial view was reduced to the main scanner, reconstruction, detection score and four essential controls. Specialist settings and additional plots are collapsed; a plain-language quick start and 10 cm scale were added. This is documented design feedback from the project owner, not a classmate beta review.
